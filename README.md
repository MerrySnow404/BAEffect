## 蓝白鼠标效果

为MC带来了蔚蓝档案风格的点击效果和光标样式。

效果演示：
![gif](https://resource-api.xyeidc.com//client/members/pics/b4ebf414)

本模组将以下两个项目带到了MC中：
- https://github.com/DoomVoss/BASpark
- https://github.com/makipom/BlueArchive-Cursors

功能完全依赖晴雪UI实现，模组本体源码仅有不同情况下光标样式的选择。

光标组中大部分未使用，如需修改样式，可以参考晴雪UI使用CSS进行覆盖式自定义。

未来计划为引进第二套光标，并补充不同情况下光标样式的变化。
